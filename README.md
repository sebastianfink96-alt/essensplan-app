# Essensplan

Installierbare Web-App (PWA) zum Planen von Gerichten für zwei Wochen, mit Einkaufsliste.

**App öffnen:** https://sebastianfink96-alt.github.io/essensplan-app/

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Diese Dateien werden automatisch aus dem (privaten) Projekt erzeugt (`tools/build_web.py`) – hier nicht von Hand ändern.
