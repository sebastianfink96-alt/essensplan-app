KI-Server einrichten

Einmalig, ca. 10 Minuten. Der Code enthält keine Geheimnisse.

  1. Unten auf Code kopieren tippen.
  2. Auf dash.cloudflare.com: Menü → Compute → Workers & Pages → Create → Start with Hello World! → Namen essensplan-ki → Deploy.
  3. Edit code öffnen, den vorhandenen Text komplett löschen, den kopierten Code einfügen, Deploy.
  4. Im Worker: Settings → Variables and Secrets → zweimal Add, Typ Secret:
    ANTHROPIC_API_KEY = dein API-Schlüssel
    APP_PASSWORD = ein langes Passwort deiner Wahl
    ELEVENLABS_API_KEY = optional, Schlüssel von elevenlabs.io für die natürliche Vorlese-Stimme
  5. Die Adresse des Workers kopieren (endet auf .workers.dev) und in der App unter Einstellungen → „KI in dieser App“ zusammen mit dem Passwort eintragen.
